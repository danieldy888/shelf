# Shelf 使用说明

Shelf 是住在 macOS 刘海里的临时托盘：暂存文件引用、复制的文字和截图，再拖到其他应用使用。空闲时它完全隐形；悬停或拖拽靠近刘海时探头提示，展开成与硬件刘海融为一体的纯黑面板。

系统要求：Apple Silicon 芯片（M1 或更新）的 Mac，macOS 13 或以上。不支持 Intel 芯片的 Mac。

## 安装

1. 下载 [Shelf.dmg](https://github.com/henryyu333/shelf/releases/latest/download/Shelf.dmg)。
2. 打开下载好的文件，把 **Shelf** 拖到 **Applications（应用程序）** 文件夹上。
3. 从“应用程序”里打开 Shelf。它常驻屏幕顶部的菜单栏，不在 Dock 上占图标。
4. 按 **Control + Option + 空格**（`⌃⌥Space`）显示托盘，也可以单击菜单栏的托盘图标。

### 第一次打开：提示“未打开 Shelf”

Shelf 是免费软件，没有经过 Apple 公证，所以 macOS 会让你确认一次。请只对从本项目 Releases 页面下载的版本这样做。

**macOS 15 或更新**

1. 在“应用程序”里双击 Shelf。系统提示未打开时，点 **完成**（不要点“移到废纸篓”）。
2. 打开 **系统设置 → 隐私与安全性**，往下滚动到 **安全性**。
3. 在“已阻止 Shelf 以保护 Mac”旁边，点 **仍要打开**。
4. 输入开机密码或用触控 ID 确认，再点一次 **仍要打开**。

**macOS 13 或 14**

在“应用程序”里按住 Control 点按（或右键点按）Shelf，选 **打开**，再在弹窗里点 **打开**。

这是只针对 Shelf 的一次性例外，不需要关闭系统安全保护。如果系统提示 App **已损坏**，不要绕过，删掉后重新下载。Apple 官方说明：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

## 日常使用

| 想做什么 | 操作 |
| --- | --- |
| 拖入文件或文件夹 | 在 Finder 拖着它往屏幕顶部中央（刘海区）移动：刘海会先探头提示，光标一进入触发区托盘即展开，直接放进去；也可以拖到探头刘海上松开 |
| 摇晃唤出暂存篮 | 拖着内容时左右快速摇晃指针，光标旁浮现一张黑色篮子卡片（放到这里）；拖到上面松开即放入 Shelf，松手后短暂显示“已放入 Shelf”再消失。拖拽结束不放开也自动消失 |
| 探头预览 | 空手把指针移到刘海上，它会向下鼓出一个小胶囊；单击胶囊展开 |
| 控制正在播放 | 展开面板上方的播放条有封面、歌名、上一首/播放暂停/下一首和一条细进度线，托盘页和剪贴板页都在；悬停刘海时会长成完整的播放器（含已播与剩余时间），按钮可以直接点，点其他位置展开托盘 |
| 正在播放开关 | 设置… → 托盘 → 「刘海显示正在播放」，或用右键菜单栏图标 → 「正在播放」：启停悬停播放器与面板播放条，立即生效（不必重启）；设置文件损坏时该项置灰 |
| 打开设置窗口 | 右键点菜单栏图标 → 设置…：所有偏好集中在一个窗口里，改完立即生效 |
| 手动打开或收起 | 按 `⌃⌥Space`，或单击菜单栏图标 |
| 收起已显示的托盘 | 再按快捷键、按 Esc、点击“收起”，或点击托盘外任意处 |
| 收好复制的文字 | 正常按 `⌘C`；约半秒自动加入托盘，无需先打开面板 |
| 收好截图 | 用 `⌃⇧⌘4` 选区；**选区直到松开鼠标时继续按住 Control**，确保复制到剪贴板而不是保存到桌面 |
| 从服务菜单收进托盘 | 在 Finder 右键选中的文件或文件夹 → 服务/快速操作 → “添加到 Shelf”；或在任意应用选中文字 → 应用菜单 → 服务 → “添加到 Shelf”。托盘短暂显示“已放入”后自动收起 |
| 拖出文件、文字或图片 | 在托盘中拖住该项，到目标应用的接收位置松开；成功拖出后托盘收起，原项默认仍保留（想让拖出去的项目自动离开托盘，见下面「拖出后从托盘移除」） |
| 拖出后从托盘移除 | 设置… → 托盘 → 打开「拖出后从托盘移除」：从托盘拖出并成功放下的项目立即从托盘消失；置顶的项目会保留；剪贴板截图只是不在托盘显示，剪贴板页仍有记录。截图和转换生成的文件会在拖出约 10 秒后才删除，让接收的应用有时间读取。从剪贴板页拖出不受影响 |
| 把一条文字复制回来 | 单击文字项，然后在编辑器等应用中按 `⌘V`；或按 `⌃⌥V` 用键盘找到它 |
| 只查看剪贴板收录的内容 | 点面板左上角（刘海左侧）的剪贴板图标；托盘页放文件、文件夹、图片（含剪贴板截图）以及拖入/服务收录/置顶的文字——未置顶的剪贴板文字只在剪贴板页 |
| 搜索剪贴板内容 | 按 `⌃⌥V`：托盘展开、焦点在搜索框，输入即按子串筛选文字（大小写不敏感；图片只在未搜索时列出）；`↑`/`↓` 移动选中，`⏎` 复制选中项并收起、焦点回到你原来的应用；`Esc` 先清空搜索、再按一次收起 |
| 置顶项目 | 右键项目 → 「置顶」；置顶行带图钉标记、在两个标签页都排最前，不被文字限额、自动清理和「清空」移除；再右键 → 「取消置顶」还原 |
| 不再记录某个应用的剪贴板 | 右键剪贴板条目 → 「不再记录来自『应用名』的内容」；它写入 `settings.json` 的 `excludedApps`，设置文件损坏时这一项置灰 |
| 更多操作 | 右键单击项目（或按住 Control 单击）：打开、在 Finder 中显示、快速查看、隔空投送、复制文字或路径、置顶、移除。对已选中的项目右键，操作作用于全部选中项 |
| 快速查看 | 选中文件或图片后按空格；再按空格或 Esc 关闭 |
| 转换图片 | 右键图片（截图、剪贴板图片，或拖进来的 jpg、png、heic、webp、tiff、gif、bmp、avif）→「转换为」：JPEG、HEIC、PNG（图片已经是哪种格式，那一项置灰）、PDF、Word（识别文字）。选中多张时是「转换 N 张为」，每张各转一份；另有「合并为一个 PDF」，按托盘里的顺序排页。选中里混有不是图片的项目时不出现这些选项 |
| 转换 PDF | 右键 PDF →「转换为」：「Word（提取文字）」或「PNG / JPEG（每页一张）」；选中多个时是「转换 N 个为」。转出的 Word 只有文字：PDF 的每一页对应 Word 的一页，原来的排版、表格、字体和图片不会带过去；扫描版的页面没有文字层，会先识别图里的文字。每页一张图片时按「名 第 2 页.png」命名，只有一页的 PDF 直接用原名。选中里同时有 PDF 和图片时不出现转换选项 |
| 转换的结果 | 转好的文件排在托盘最前面并已选中，直接拖出即可；图片左下角标出新格式。文件名沿用原名、只换扩展名，重名时加「 2」。原文件不会被改动。转好的文件存在 Shelf 的数据文件夹里，在托盘里移除它，文件也一起删除——要长期保留请先拖到别处 |
| 图片转成 Word | 先放识别出的文字（按行分段，可以编辑），下面附上原图，纸张 A4。只还原文字内容，不还原表格、字体和排版；没识别到文字时只放原图，并提示「没有识别到文字」。第一次识别要准备文字识别模型，可能需要十几秒 |
| 转换进度与取消 | 识别文字、合并多张时，面板上方会出现「正在转成…」，右边的 × 可以取消，已经转好的会保留；某一张失败不影响其他张，完成后提示成功和失败各几项 |
| 缩小图片 | 右键图片 →「缩小图片」（多张时「缩小 N 张图片」）→ 大（长边 2560 像素）/ 中（1600）/ 小（800）。只缩小不放大：本来就比所选尺寸小的图片保持原尺寸；选中的图片都不超过某个尺寸时，那一项置灰。JPEG、PNG、HEIC 保持原格式，其他格式存成 JPEG；文件名加上尺寸，如「照片 1600px.jpg」。完成后提示缩小前后的总大小 |
| 压缩为 zip | 右键文件、文件夹或图片（可多选）→「压缩为 zip」（多选时「压缩 N 项为 zip」）。文件夹保留里面的结构，符号链接按链接保存，不打包 .DS_Store；单项用原名，如「报告.pdf.zip」，多项为「首项名 等 N 项.zip」；同名文件在压缩包里自动改名为「名 2」。进行中可以在面板上方取消，取消后不留下半个压缩包 |
| 剪贴板记录开关与条数 | 设置… → 剪贴板：「记录复制的内容」开关与「保留条数 30/100/300」；右键菜单栏图标 → 「剪贴板记录」有同样的开关与选项，改哪边都立即生效 |
| 清空当前页 | 点列表标题右边的垃圾桶「清空」——只移除这一页里置顶以外的项目（托盘页不动剪贴板记录，剪贴板页不动托盘；搜索时不显示）；置顶项连同保存的图片保留，文件引用的原文件不会删除 |
| 开启刘海拖放保护（可选） | 设置… → 通用 → 「刘海拖放保护」旁的「开启…」，或右键菜单栏图标选择“开启刘海拖放保护…”，再在系统设置里打开 Shelf |
| 自动清理旧内容 | 设置… → 托盘 → 「自动清理旧内容」（从不 / 1 天 / 7 天 / 30 天）；右键点菜单栏图标 → 「自动清理」有同样的期限可选，默认不自动清理 |
| 检查与安装更新 | 右键点菜单栏图标 → 「检查更新…」手动查询；有新版本时托盘底部出现提示、菜单多出「安装更新（vX）…」，选择后才开始下载；装好后菜单项变成「重新启动 Shelf 完成更新」。后台检查每天一次，在 设置… → 通用 → 「自动检查更新」关闭（详见「自动更新」） |
| 查看 AI 用量 | 先在 设置… → AI 用量 打开「在刘海里显示 AI 用量」（默认关闭）：刘海左侧会多出第三个图标，页面显示 Codex 与 Claude Code 的套餐剩余额度（内外双圈：外圈每周、内圈 5 小时，悬停卡片看详情）和本机 token 用量（omp、Claude Code、Codex 的堆叠柱图与汇总，按 今天 / 7 天 / 30 天 / 全部 切换，可点标题右侧的刷新按钮更新）。各额度卡和本机来源都能在同组设置里单独关掉 |
| 退出 Shelf | 右键点菜单栏图标，选择“退出 Shelf” |

托盘与刘海融为一体：有刘海的 Mac 上纯黑面板从刘海里长出来、分不出边界；没有刘海的显示器上同样从顶部中央展开成一块黑色圆角面板。空闲时窗口贴在顶边且完全透明；刘海这一条能接收点击和拖入，刘海以下点穿，不挡住下面的应用。

文字历史默认最多保留 **30 条文字**（设置… → 剪贴板 → 「保留条数」可改为 100 或 300 条，右键菜单栏图标 → 「剪贴板记录」同款选项），单条文字不限制长度。列表只显示简短摘要，单击复制或拖出时仍是完整正文。重复文字移到顶部，不新增重复项；文件和图片不占文字限额，也没有数量上限，不需要时手动移除即可。置顶的文字不占限额（不会被淘汰），两个标签页都把置顶项排在最前。

每条剪贴板记录会记住复制它的应用；右键剪贴板条目可以选择「不再记录来自该应用的内容」，该应用的标识符会写入 `settings.json` 的 `excludedApps`（不区分大小写）。想恢复记录，在 **设置… → 剪贴板 → 排除的应用** 里点该行的「移除」，或退出 Shelf 后从 `settings.json` 里删掉它。

面板最上面一行在刘海两侧：左边是托盘和剪贴板两个图标（鼠标停在上面会显示名字），右边是设置和收起。托盘页显示全部内容，剪贴板页只显示剪贴板收录的文字和图片；当前页的名字和数量写在列表上方。按 `⌃⌥V` 会直接打开剪贴板页并把焦点放进搜索框，全程不需要鼠标（这时这一行会移到菜单栏下方）；复制选中项后托盘收起，并把焦点交还给你之前所在的应用。这个快捷键按下时 Shelf 才会短暂获得键盘，其余打开方式（悬停、拖入、单击图标）一如既往不抢焦点。

当前页有未置顶的内容时，列表标题右边会显示“清空”按钮：点击一次移除这一页里置顶以外的项目并立即生效，误清空不会弹确认框，请留意。托盘页的清空不会动剪贴板记录——剪贴板收录只被移出托盘显示、历史仍保留，反过来也一样。置顶的项目连同 Shelf 替它们保存的图片会保留下来；真正删除的清空项会删除 Shelf 自己保存在 `images/` 里的剪贴板图片与截图，但文件引用指向的原文件始终不会被删除；只想移除个别项目时，右键该项目 → 「移除」。

自动清理每小时检查一次，选择后立即执行一次。“超过 N 天”从项目最近一次放入托盘算起：同一内容再次复制或拖入会重新计时。清理与“清空”一样，只删除 Shelf 自己保存的图片，绝不删除文件引用指向的原文件。

托盘展开且你正在使用时，Shelf 会临时占用空格键和 Esc（焦点在剪贴板搜索框时不占用，按键留给输入）；点一下其他应用就会归还。

文件拖入只记录路径，不复制原文件。原文件被移动或删除后，再打开托盘会标灰并显示“文件已移动”；可以手动移除该项。重启时会清理真正不存在的引用。

图片较多时会分批生成缩略图，相机照片会按照片记录的方向显示。再次复制同一张图片时，Shelf 会检查已保存的内容；如果文件被改写或损坏，会用本次复制的原图恢复。

拖拽进入顶部接收区后如果没有放入内容，离开接收区或面板后托盘会自动缩回刘海。悬停只显示探头胶囊，不会自行展开；单击胶囊或快捷键唤出的托盘会保持展开，直到你明确收起。个别应用的拖拽不经过系统拖拽剪贴板，刘海可能不会探头；这时按快捷键打开托盘再拖进去。

## 设置窗口

右键点菜单栏图标 → **设置…** 会打开一个普通窗口，把所有偏好集中在一处。窗口居中出现在光标所在显示器上，已经开着时再次打开只会把它调到最前，不会开出第二个。

| 分组 | 内容 |
| --- | --- |
| 通用 | 「开机时自动启动」开关（macOS 13+，通过 SMAppService 注册为登录项）；「自动检查更新」开关（默认开启，见「自动更新」一节）；「刘海拖放保护」显示当前状态，未开启时提供「开启…」按钮直接跳到系统授权 |
| AI 用量 | 「在刘海里显示 AI 用量」总开关（默认关）；「套餐额度」选查 Codex、Claude Code 的额度；「本机用量」选统计 omp、Claude Code、Codex 的本地记录 |
| 剪贴板 | 「记录复制的内容」开关；「保留条数」30 / 100 / 300 三档；「排除的应用」列表（图标 + 应用名 + bundle id），每行右侧「移除」按钮。加入列表仍用条目右键菜单里的「不再记录来自…」 |
| 托盘 | 「自动清理旧内容」从不 / 1 天 / 7 天 / 30 天；「刘海显示正在播放」开关 |
| 快捷键 | 只读展示 `⌃⌥Space` 显示/收起、`⌃⌥V` 剪贴板搜索（快捷键是编译期常量，改它需要重新打包） |
| 底部 | 版本号，以及「打开数据文件夹」按钮（在 Finder 里打开 `~/Library/Application Support/Shelf/`） |

每个控件改完**立即生效**，和菜单栏子菜单调用的是同一套设置逻辑，所以两边永远不会不一致：在窗口里改完，菜单栏再打开时显示的就是新状态（反过来也一样）。内容超出窗口高度时窗口内部滚动；按 `Esc` 或 `⌘W` 关闭窗口。

**开机时自动启动**需要 `Shelf.app` 在“应用程序”文件夹里：注册失败时（例如从别处直接运行开发版）原因会直接显示在开关下方，不会静默失败。开关状态每次打开窗口时都从系统重新读取，所以你在系统设置里手动改过也会如实显示。

**settings.json 损坏时**，窗口顶部会显示红色提示条，说明设置已按默认值运行，并且「剪贴板 / 托盘」两组控件与「自动检查更新」开关全部锁定（置灰、点不动），避免把坏文件覆盖成一份看似正常的默认设置。修好文件后重新打开 Shelf 即可恢复。

## 开机自动运行

1. 打开 **设置…**（右键菜单栏图标 → 设置…）。
2. 在「通用」里打开 **开机时自动启动**。
3. 下次登录后 Shelf 会自动常驻菜单栏。

如果注册失败（窗口里会显示原因），可以用系统自带的方式手动添加，效果相同：

1. 确认 `Shelf.app` 已经放在“应用程序”文件夹。
2. 打开 **系统设置 → 通用 → 登录项**（部分系统叫“登录项与扩展”）。
3. 在“登录时打开”的列表点击 **+**，选择 `Shelf.app`。

## 自动更新

正式版 Shelf 会自己检查新版本：启动后不久查一次，之后每天一次，查询对象是本项目在 GitHub 的**最新 Release**（`henryyu333/shelf`）。如果你另外开启了 AI 用量页，它还会向 Codex 与 Claude Code 各自的官方地址查询套餐额度（见「数据与隐私」）。除此之外没有其他网络请求——更新检查是标准的 HTTPS GET，User-Agent 只写明应用名与版本（如 `MyGo/0.5.5 Shelf/1.0.8`），不发送任何个人信息、设备标识或使用数据；更新包附带数字签名，安装前会验证签名与完整哈希，只有用发布方私钥签名的版本才会被装上。

发现新版本时不会有弹窗打扰：托盘底部出现一行提示，菜单栏图标的右键菜单里多出「安装更新（vX）…」。只有你选择它才会下载并替换应用；装好后菜单项变成「重新启动 Shelf 完成更新」，重启后进入新版本（也可以直接退出再打开）。随时可以用右键菜单的「检查更新…」手动查询。

不想让它联网检查：设置… → 通用 → 关闭「自动检查更新」，立即生效；也可以先退出 Shelf，把 `settings.json` 里的 `"autoCheckUpdates"` 改成 `false` 再打开。关闭后手动检查仍然可用。开发构建（`go build`/`mygo dev` 的产物）不做检查，菜单里的检查会说明该构建未启用自动更新。

提醒：macOS 的辅助功能授权跟应用绑定，**更新后请把「刘海拖放保护」重新开启一次**（设置… → 通用 → 「开启…」）。

## 数据与隐私

数据保存在：

```text
~/Library/Application Support/Shelf/
  state.json        托盘内容（含图片清单）
  settings.json     设置
  images/           剪贴板图片与截图
  .lock             防止同时运行两个 Shelf 的锁文件，运行时不要删除
  usage-cache/      AI 用量页的本地用量统计缓存（开启过才有，删掉只是下次统计变慢）
```

在 Finder 按 `⌘⇧G`，粘贴 `~/Library/Application Support/Shelf/`，即可找到它。备份时先退出 Shelf，再复制整个文件夹；恢复时同样先退出。

不想让 Shelf 记录复制的内容：设置… → 剪贴板，关闭「记录复制的内容」即可（右键菜单栏图标 → 「剪贴板记录」里的同一开关也一样），立即生效、不必重启。也可以先退出 Shelf，把 `settings.json` 里的 `"clipboardHistory": true` 改成 `false` 再打开；改回 `true` 即可恢复。各种偏好都可以在设置窗口里改；它们存在 `settings.json` 里：`"clipboardHistory"`、`"clipboardLimit"`、`"retentionDays"`、`"excludedApps"`、`"autoCheckUpdates"`，正在播放开关对应 `"islandNowPlaying"`，拖出后从托盘移除对应 `"removeAfterDrag"`，AI 用量页的开关都在 `"aiUsage"` 里（默认 `enabled` 为 `false`，各来源开关默认 `true`）；除 `"retentionDays"`（默认 0，不清理）、`"clipboardLimit"`（默认 30）、`"removeAfterDrag"`（默认 `false`）与 `"aiUsage.enabled"` 外默认都是 `true`。文件写错时，Shelf 会提示并按默认设置运行，不会改动你的文件；此时设置窗口会锁定这几组控件，等你修好文件再改。

同一时间只能运行一个 Shelf：再打开第二个时，它会提示“已在运行”并立即退出，不会影响已有内容。

**文字历史以明文保存，不提供加密。** 密码管理器标记为隐私的密码不会被记录，但其他复制的内容（验证码、客户资料等）都可能被收进历史。不希望某段内容被记录时，先退出 Shelf 再复制。删除文件引用不会删除你的原文件；在剪贴板页移除剪贴板图片会清理 Shelf 自己保存的图片（托盘页的移除只让它不再显示在托盘）。

Shelf 不上传任何内容：没有云同步、遥测或统计。联网请求只有两类：向 GitHub Releases 的自动更新检查（见「自动更新」一节：默认开启，可在设置里关闭；请求不含个人信息），以及可选的 AI 用量页的额度查询。日常使用不需要辅助功能、输入监控或屏幕录制授权。只有“刘海拖放保护”需要辅助功能授权，这一项是可选的：设置… → 通用 → 「刘海拖放保护」旁的「开启…」（或右键点菜单栏图标，选择“开启刘海拖放保护…”），然后在系统设置里打开 Shelf。开启后，拖着内容靠近刘海时，指针会停在托盘接收区里，不会顶到屏幕最上沿。每次更新 Shelf 后要重新开启一次；设置窗口或菜单里显示“刘海拖放保护已开启”就说明已经生效。

**AI 用量页**默认关闭。打开后它会读取本机这些工具已保存的登录信息（Codex 的 `~/.codex/auth.json`、钥匙串里的 Claude Code 凭据），只用来向它们各自的官方地址查询套餐剩余额度——登录信息不会发给任何其他地方，也永远不会替你登录或刷新登录。「本机用量」只在这台电脑上读取 omp、Claude Code、Codex 的会话记录文件做汇总，统计结果不上传；每个来源都可以在设置里单独关掉。关掉总开关后页面消失，不会再有任何读取和查询。

如果保存的数据无法读取，Shelf 会提示原因；确认后本次启动退出，不创建菜单栏托盘或占用快捷键，也不会用空内容覆盖原文件。请先备份数据文件夹再处理，然后重新打开 Shelf。

## 卸载

1. 右键菜单栏图标 → 退出 Shelf。
2. 把“应用程序”里的 Shelf 移到废纸篓。
3. 如果连保存的内容也要删除，删掉 `~/Library/Application Support/Shelf/` 文件夹。

## 修改快捷键与灵敏度

设置窗口里的「快捷键」一栏只是只读展示：快捷键和灵敏度都是编译期常量，要改需要改源码后自己重新打包（需要 Go 1.27 或以上以及 Xcode Command Line Tools）。

1. 下载本项目源码，用代码编辑器打开 `config.go`。
2. 找到 `trayShortcut = "Ctrl+Alt+Space"`，改成你想要的组合，例如 `"Ctrl+Alt+S"`。只改引号里的内容。
3. 同一个文件里还可以调整：`notchTriggerWidth` / `notchTriggerHeight`（拖拽靠近刘海的触发区宽和高，280×64 pt）、`notchHoverPadX` / `notchHoverPadY`（空手悬停刘海的感应余量，8×4 pt）、`edgeLeaveDelay`（离开后多久收起，350 毫秒）。
4. 在终端进入项目目录，运行：

```sh
go run github.com/egoist/mygo/cmd/mygo build
```

5. 打包好的 `Shelf.app` 和 `.dmg` 在 `dist.noindex/darwin-arm64/` 里。先退出正在运行的 Shelf，再用新的替换。

面板底部的快捷键提示会自动跟着变，不需要另外修改。

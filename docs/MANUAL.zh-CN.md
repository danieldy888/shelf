# ShelfU 使用说明

ShelfU 是住在 macOS 刘海里的工具：文件托盘、剪贴板、正在播放、工具卡、AI 用量和桌面小组件，都从刘海里长出来。空闲时它完全隐形；悬停或拖拽靠近刘海时先探头提示。点一下先是一个小岛（左边迷你播放器，右边每个页面一个图标），点页面图标才展开成 420 × 250 的纯黑面板；如果是拖着东西过来，一进入投放带就直接打开「托盘」页等着接收。每一页都是这个尺寸，所以面板停在菜单栏下面，不会盖住菜单栏和窗口。

系统要求：Apple Silicon 芯片（M1 或更新）的 Mac，macOS 13 或以上。不支持 Intel 芯片的 Mac。

## 安装

1. 下载 [ShelfU.dmg](https://github.com/henryyu333/shelfu/releases/latest/download/ShelfU.dmg)。
2. 打开下载好的文件，把 **ShelfU** 拖到 **Applications（应用程序）** 文件夹上。
3. 从“应用程序”里打开 ShelfU。它常驻屏幕顶部的菜单栏，不在 Dock 上占图标。
4. 按 **Control + Option + 空格**（`⌃⌥Space`）打开 ShelfU 的小岛，也可以单击菜单栏的托盘图标。

### 第一次打开：提示“未打开 ShelfU”

ShelfU 是免费软件，没有经过 Apple 公证，所以 macOS 会让你确认一次。请只对从本项目 Releases 页面下载的版本这样做。

**macOS 15 或更新**

1. 在“应用程序”里双击 ShelfU。系统提示未打开时，点 **完成**（不要点“移到废纸篓”）。
2. 打开 **系统设置 → 隐私与安全性**，往下滚动到 **安全性**。
3. 在“已阻止 ShelfU 以保护 Mac”旁边，点 **仍要打开**。
4. 输入开机密码或用触控 ID 确认，再点一次 **仍要打开**。

**macOS 13 或 14**

在“应用程序”里按住 Control 点按（或右键点按）ShelfU，选 **打开**，再在弹窗里点 **打开**。

这是只针对 ShelfU 的一次性例外，不需要关闭系统安全保护。如果系统提示 App **已损坏**，不要绕过，删掉后重新下载。Apple 官方说明：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

## 日常使用

| 想做什么 | 操作 |
| --- | --- |
| 拖入文件或文件夹 | 在 Finder 拖着它往屏幕顶部中央（刘海区）移动：刘海会先探头提示，光标一进入触发区就打开「托盘」页，直接放进去；也可以拖到探头刘海上松开 |
| 摇晃唤出暂存篮 | 拖着内容时左右快速摇晃指针，光标旁浮现一张黑色篮子卡片（放到这里）；拖到上面松开即放入 ShelfU，松手后短暂显示“已放入 ShelfU”再消失。拖拽结束不放开也自动消失 |
| 探头预览 | 空手把指针移到刘海上，它会向下鼓出一个小胶囊；单击胶囊打开小岛 |
| 控制正在播放 | 小岛左边的迷你播放器有封面、歌名、歌手、音频条和播放暂停；打开「主页」的音乐小组件是完整播放器：上一首 / 播放暂停 / 下一首、可以拖动跳转的进度条，以及系统默认输出设备的音量。悬停刘海时只向左右各长出一小截：左边封面，右边音频条（播放时跳动，暂停时静止），不向下遮挡窗口，也没有按钮；单击它打开小岛 |
| 正在播放开关 | 设置… → 托盘 → 「刘海显示正在播放」，或用右键菜单栏图标 → 「正在播放」：启停悬停时的两翼、小岛的迷你播放器和「主页」的音乐小组件，立即生效（不必重启）；设置文件损坏时该项置灰 |
| 打开设置窗口 | 右键点菜单栏图标 → 设置…：所有偏好集中在一个窗口里，改完立即生效 |
| 切换语言 | 设置… → 通用 → 「语言」选跟随系统 / 简体中文 / English：立即生效，不用重新打开 ShelfU；跟随系统时 Mac 的首选语言是中文就显示中文（简体、繁体都显示简体中文），其他语言显示英文；日期和时间按 Mac 的地区和 12/24 小时制显示，服务菜单里的「添加到 ShelfU」跟系统语言走 |
| 手动打开或收起 | 按 `⌃⌥Space`，或单击菜单栏图标：打开的是小岛，再按一次收起 |
| 收起已显示的页面 | 按 Esc 先回到小岛，再按一次 Esc 就收回刘海；点面板外（菜单栏那一条高度以内不算）、点「收起」或再按一次快捷键都直接收起，不经过小岛 |
| 收好复制的文字 | 正常按 `⌘C`；约半秒自动加入托盘，无需先打开面板 |
| 收好截图 | 用 `⌃⇧⌘4` 选区；**选区直到松开鼠标时继续按住 Control**，确保复制到剪贴板而不是保存到桌面 |
| 从服务菜单收进托盘 | 在 Finder 右键选中的文件或文件夹 → 服务/快速操作 → “添加到 ShelfU”；或在任意应用选中文字 → 应用菜单 → 服务 → “添加到 ShelfU”。托盘短暂显示“已放入”后自动收起 |
| 拖出文件、文字或图片 | 在托盘中拖住该项，到目标应用的接收位置松开；成功拖出后面板收起，原项默认仍保留（想让拖出去的项目自动离开托盘，见下面「拖出后从托盘移除」） |
| 拖出后从托盘移除 | 设置… → 托盘 → 打开「拖出后从托盘移除」：从托盘拖出并成功放下的项目立即从托盘消失；置顶的项目会保留；剪贴板截图只是不在托盘显示，剪贴板页仍有记录。截图和转换生成的文件会在拖出约 10 秒后才删除，让接收的应用有时间读取。从剪贴板页拖出不受影响 |
| 把一条文字复制回来 | 单击文字项，然后在编辑器等应用中按 `⌘V`；或按 `⌃⌥V` 用键盘找到它 |
| 只查看剪贴板收录的内容 | 点小岛上的剪贴板图标；托盘页放文件、文件夹、图片（含剪贴板截图）以及拖入/服务收录/置顶的文字——未置顶的剪贴板文字只在剪贴板页 |
| 搜索剪贴板内容 | 按 `⌃⌥V`：「剪贴板」页直接打开、焦点在搜索框，输入即按子串筛选（大小写不敏感）；`↑`/`↓` 移动选中，`⏎` 复制选中项并收起、焦点回到你原来的应用；`Esc` 先清空搜索、再按一次收起。剪贴板里的截图和图片会在后台用本机文字识别读一遍（一次一张，不联网），图中文字也能被搜到：命中的图片第二行显示「图中文字：…」和命中的片段；还没识别完的图片暂时只在未搜索时列出 |
| 置顶项目 | 右键项目 → 「置顶」；置顶行带图钉标记、在两个标签页都排最前，不被文字限额、自动清理和「清空」移除；再右键 → 「取消置顶」还原 |
| 不再记录某个应用的剪贴板 | 右键剪贴板条目 → 「不再记录来自『应用名』的内容」；它写入 `settings.json` 的 `excludedApps`，设置文件损坏时这一项置灰 |
| 更多操作 | 右键单击项目（或按住 Control 单击）：打开、在 Finder 中显示、快速查看、隔空投送、复制文字或路径、复制图片（单张图片时）、置顶、移除。对已选中的项目右键，操作作用于全部选中项 |
| 复制图片 | 在托盘里选中一张图片后按 `⌘C`（无需先激活 ShelfU；切走页面、关闭面板或打开设置后会归还按键），或右键图片 →「复制图片」：剪贴板里是 PNG 图片数据，不是文件路径；提示「已复制图片 · 在其他应用按 ⌘V 粘贴」。文件项不变，多选时只对单张可用 |
| 识别文字并复制 | 右键一张图片（截图、剪贴板图片或图片文件）→「识别文字并复制」：已经识别过的直接复制，没有就当场识别；成功提示「已复制识别出的文字 · N 字」，文字同时记进剪贴板页（来源显示「框选文字」），没有文字时提示「没有识别到文字」。后台正在识别别的图片时会排队，完成后自动复制。全部在本机完成 |
| 框选屏幕文字 | 按 `⌃⌥O`，或右键菜单栏图标 →「框选文字」，或点工具页的「框选文字」卡，然后用系统自带的框选界面框一块区域（Esc 取消，空格切换成选窗口）：区域里的文字在本机识别后直接复制到剪贴板，并记进剪贴板页（来源显示「框选文字」），刘海提示「已复制识别出的文字 · N 字」；没有文字时提示「没有识别到文字」。同一时间只做一轮：一轮没结束时再按快捷键不会开第二轮，往卡片上拖图片会提示「正在识别，请稍候」。截图不保存、不联网 |
| 框选文字的权限 | 需要「屏幕录制」权限。没开时面板里会出现说明卡：点「打开系统设置」，在 隐私与安全性 → 屏幕录制 里打开 ShelfU，然后**退出并重新打开 ShelfU** 才会生效，再按 `⌃⌥O` 即可。也可以用设置里的「系统权限」开关一起开（见「开启系统权限」）。ShelfU 不在启动时检查或申请这项权限 |
| 工具页 | 点小岛上的「工具」图标：一页动作卡，4 列排列。默认八张正好两行（不滚动），顺序是框选文字、压缩到 1 MB、转成 PDF、打成 zip、转 JPEG、转 Word、解压、缩小图片；隔空投送等其余动作卡在「+」打开的目录里，加多了超过两行就在页内滚动 |
| 用动作卡 | 点按动作卡：对托盘里选中的、它能处理的项目执行（例如「转 JPEG」只处理选中的图片），结果和右键转换一样放进托盘最前面；没有合适的选中项时卡片轻摇并提示「把文件拖到这里」，转换任务正在进行时提示「一次只跑一个任务，请稍候」。也可以把文件直接拖到卡片上松开；「框选文字」卡接收图片，会识别图里的文字并复制 |
| 编辑工具页 | 长按任一卡片约半秒，或点页面顶部那一行右边的铅笔图标，进入编辑：卡片轻轻摆动，拖动可以排序，点 ⊖ 移除，点 + 打开卡片目录添加。点「完成」或按 Esc 结束（在目录里按 Esc 只关目录）。布局存在数据文件夹的 `layout.json` 里 |
| 主页 | 点小岛上的「主页」图标：四列两行的画布，小组件各占 1×1、2×1 或 2×2 格，没放东西的格子就空着。这里放音乐、保持唤醒、AI 用量、最近文件、剪贴板最新 |
| 主页的音乐小组件 | 2×2（默认）是完整播放器：封面、歌名和「歌手 · 应用」、已播时间 + 可拖动的进度条 + 剩余时间、上一首 / 播放暂停 / 下一首、音量行。拖进度条松手后跳转，拖音量条松手后设置系统默认输出设备的音量；设备不能调音量时音量行变灰。2×1 保留封面、标题和播放暂停；1×1 只有封面和歌名，点一下切换播放。没有在播放时显示空状态 |
| 编辑主页 | 长按任一小组件约半秒，或点页面顶部那一行右边的铅笔图标，进入编辑：小组件轻轻摆动，拖到空格即吸附，点左上角 ⊖ 移除，拖右下角把手切换到下一个放得下的尺寸（1×1 / 2×1 / 2×2）。第一个空格上会画一个虚线「+」格，点它打开「小组件目录」：目录只列还没放在主页或桌面上的小组件，选一个就放到第一个放得下的空格（默认尺寸放不下时自动用更小的尺寸），然后回到编辑网格；格子全被占满时「+」改到返回行「完成」左边，实在放不下会提示「主页没有空位，先移除一个小组件」并留在目录里。点「完成」或按 Esc 结束（在目录里按 Esc 只关目录）。布局存在 `layout.json` 里 |
| 固定到桌面 | 编辑时把小组件或卡片拖出面板：出了面板会继续跟着光标显示，松开就变成桌面上的一张小浮窗，保留点按和接收文件；拖回面板里松开则放回原位。浮窗不会抢走你正在打字的应用的键盘焦点。拖动浮窗可以移动位置，也可以拖到另一块显示器上 |
| 贴边收起 | 把浮窗松在屏幕左右边缘 24pt 以内，它会收成一条贴边的窄条；鼠标移上去展开，移开 0.6 秒后收回；拖着文件靠近窄条 40pt 以内也会展开，可以直接放进去。同一边的多条会自动错开排列 |
| 浮窗的右键菜单 | 右键浮窗：「始终展开」（贴边的才有，不再自动收回）、「放回刘海」（小组件回到「主页」原来的格子，动作卡回到「工具」页）、「从桌面移除」（卡片不回页面，可以再从目录加回来）。把浮窗拖到刘海正下方，刘海提示「松开放回」，松手也会放回 |
| 拖到刘海直接处理 | 拖着文件靠近刘海，面板直接打开「托盘」页；文件在面板上时，页面内容换成「放入托盘」宽格和按文件类型出现的最多 4 个动作格，顶部那一行写「投放」和数量：全是图片 →「压缩到 1 MB」「转成 PDF」（多张时「合成一个 PDF」）「转 JPEG」（全是 JPEG 时为「转 PNG」）「隔空投送」；全是 PDF →「转 Word」「每页存成图片」「打成 zip」「隔空投送」；全是压缩包 →「解压」「隔空投送」；其他文件或文件夹 →「打成 zip」「隔空投送」。松手在哪一格就执行哪一格，结果放进托盘最前面，原文件不放进托盘；隔空投送只打开系统面板。松在宽格或其他地方 = 放入托盘。已有转换任务在进行时，动作格暂时不可用 |
| 快速查看 | 选中文件或图片后按空格；再按空格或 Esc 关闭 |
| 转换图片 | 右键图片（截图、剪贴板图片，或拖进来的 jpg、png、heic、webp、tiff、gif、bmp、avif）→「转换为」：JPEG、HEIC、PNG（图片已经是哪种格式，那一项置灰）、PDF、Word（识别文字）。选中多张时是「转换 N 张为」，每张各转一份；另有「合并为一个 PDF」，按托盘里的顺序排页。选中里混有不是图片的项目时不出现这些选项 |
| 转换 PDF | 右键 PDF →「转换为」：「Word（提取文字）」或「PNG / JPEG（每页一张）」；选中多个时是「转换 N 个为」。转出的 Word 只有文字：PDF 的每一页对应 Word 的一页，原来的排版、表格、字体和图片不会带过去；扫描版的页面没有文字层，会先识别图里的文字。每页一张图片时按「名 第 2 页.png」命名，只有一页的 PDF 直接用原名。选中里同时有 PDF 和图片时不出现转换选项 |
| 转换的结果 | 转好的文件排在托盘最前面并已选中，直接拖出即可；图片左下角标出新格式。文件名沿用原名、只换扩展名，重名时加「 2」。原文件不会被改动。转好的文件存在 ShelfU 的数据文件夹里，在托盘里移除它，文件也一起删除——要长期保留请先拖到别处 |
| 图片转成 Word | 先放识别出的文字（按行分段，可以编辑），下面附上原图，纸张 A4。只还原文字内容，不还原表格、字体和排版；没识别到文字时只放原图，并提示「没有识别到文字」。第一次识别要准备文字识别模型，可能需要十几秒 |
| 转换进度与取消 | 识别文字、合并多张时，页面左上角那一行出现一个小进度圈：鼠标停在上面看「正在转成 JPEG · 2/3」，点它出现「取消」，已经转好的会保留；某一张失败不影响其他张，完成后提示成功和失败各几项 |
| 缩小图片 | 右键图片 →「缩小图片」（多张时「缩小 N 张图片」）→ 大（长边 2560 像素）/ 中（1600）/ 小（800）。只缩小不放大：本来就比所选尺寸小的图片保持原尺寸；选中的图片都不超过某个尺寸时，那一项置灰。JPEG、PNG、HEIC 保持原格式，其他格式存成 JPEG；文件名加上尺寸，如「照片 1600px.jpg」。完成后提示缩小前后的总大小 |
| 压缩为 zip | 右键文件、文件夹或图片（可多选）→「压缩为 zip」（多选时「压缩 N 项为 zip」）。文件夹保留里面的结构，符号链接按链接保存，不打包 .DS_Store；单项用原名，如「报告.pdf.zip」，多项为「首项名 等 N 项.zip」；同名文件在压缩包里自动改名为「名 2」。进行中点左上角的进度圈可以取消，取消后不留下半个压缩包 |
| 压缩到指定大小 | 右键图片（可多选）→「压缩到」→ 500 KB / 1 MB / 2 MB / 5 MB 以内。JPEG、HEIC 保持原格式，先降低画质、仍然太大再逐步缩小尺寸；带透明背景的图片保持 PNG，只缩小尺寸；其他格式存成 JPEG。照片方向会摆正。本来就小于目标的图片跳过不处理，选中的图片都已经够小时那一档置灰。结果文件名为「原名（压缩）」，完成后提示压缩了几张、几张本来就够小、压缩前后的总大小；个别图片实在压不到目标时，会保留能压到的最小结果并在提示里说明 |
| 解压 | 右键压缩包（可多选）→「解压」（多选时「解压 N 项」），支持 zip、tar（含 .tar.gz、.tgz、.tar.bz2、.tbz、.tar.xz 等）、7z 和 rar。每个压缩包解成一个同名文件夹放进托盘；压缩包里只有一个文件夹时直接用它，不再多套一层；`__MACOSX` 和以「._」开头的系统附带文件会跳过。进行中点左上角的进度圈可以取消，取消或失败都不会留下半成品；加密的压缩包会提示无法解压。解出的文件夹和其他转换结果一样存在 ShelfU 的数据文件夹里，在托盘里移除它会一起删除——要长期保留请先拖到别处 |
| 批量重新命名 | 右键托盘里的一个或多个文件、文件夹 →「重新命名…」（多选时「重新命名 N 项…」），打开改名窗口，三种方式和 Finder 一样：「替换文字」（查找 / 替换为）、「添加文字」（加在名称前或后）、「名称加序号」（名称、起始号、位数 1–4、序号在名称前或后）。扩展名始终保留。下方实时预览「旧名 → 新名」，有问题的行标红并写明原因（已存在同名文件、和本批其他项目重名、名字为空或含有「/」「:」、名字或路径太长、不能同时改文件夹和它里面的项目），有冲突时「改名」不可点。回车改名，Esc 取消。**这里改的是磁盘上的真实文件名**，托盘里的项目会跟着更新；不会覆盖任何已有文件，中途出错会全部改回原名。完成后面板底部提示「已重新命名 N 项」并带「撤销」按钮，可以把这一批改回原名（只能撤销最近一次；原名已被别的文件占用时会提示无法撤销，不会覆盖）。截图、剪贴板图片和文字项不能改名 |
| 剪贴板保留条数 | 复制的文字和截图始终自动收好，没有开关。设置… → 剪贴板 →「保留条数」30/100/300；右键菜单栏图标 →「剪贴板记录」有同样的选项，改哪边都立即生效 |
| 清空当前页 | 点页面顶部那一行右边的垃圾桶「清空」——只移除这一页里置顶以外的项目（托盘页不动剪贴板记录，剪贴板页不动托盘；搜索时不显示）；置顶项连同保存的图片保留，文件引用的原文件不会删除 |
| 开启系统权限 | 设置… → 系统权限 里打开那一个开关，或右键菜单栏图标 →「开启系统权限（还差 N 项）…」：按顺序打开「完整磁盘访问」（拖入不再弹窗）、「辅助功能」（刘海拖放保护）和「屏幕录制」（框选文字）三页系统设置，你在每页打开 ShelfU 的开关后会自动走到下一项；已经开好的直接跳过。「完整磁盘访问」列表里一开始没有 ShelfU：点 +，选 ShelfU，或把访达里已经选中的 ShelfU 拖进列表。最后点「重新打开 ShelfU」让授权生效。全部开好后开关保持打开，菜单里显示灰色的「系统权限已全部开启」 |
| 自动清理旧内容 | 设置… → 托盘 → 「自动清理旧内容」（从不 / 1 天 / 7 天 / 30 天）；右键点菜单栏图标 → 「自动清理」有同样的期限可选，默认不自动清理 |
| 保持唤醒 | 右键菜单栏图标 →「保持唤醒」：30 分钟 / 1 小时 / 2 小时 / 4 小时 / 一直（直到关闭）。这段时间里 Mac 不会因为空闲自动睡眠，屏幕照常可以变暗熄灭；勾选「屏幕也保持亮着」后屏幕也不会熄灭。当前时长前面打勾，重新选一个时长会重新计时；「关闭」随时停止。开启期间，打开任何一页都能在左上角那一行看到月亮图标：鼠标停在上面看剩余时间，点一下结束。时间到、关闭或退出 ShelfU 后恢复正常睡眠；重新打开 ShelfU 时默认是关闭的 |
| 充电提示 | 插上电源时，刘海马上向两边各变宽一截，停 3 秒：左边「⚡ 正在充电」，右边绿色电量条 + 电量数字。接着电源充到 100% 时提醒一次「已充满」；不插电时电量降到 20% 和 10% 各提醒一次「电量低」（红色电量条，停 5 秒）。「已复制」这类状态提示正在显示时，充电提示等它结束再出现。没有电池的 Mac 不提示。设置… →「实时活动」→「充电提示」可以关 |
| 耳机连接提示 | 蓝牙耳机或音箱连上时，刘海下沿长出一条提示，停 3.5 秒：耳机名字；AirPods 在系统给出电量时显示「左 / 右 / 盒」的电量，拿不到就写「已连接」。断开时提示「已断开」2 秒。鼠标、键盘连上不提示。设置… →「实时活动」→「耳机连接提示」可以关 |
| 下载进度 | 浏览器（Safari、Chrome、Edge、Brave、Firefox）往「下载」文件夹下载时，刘海两翼显示蓝色进度环和百分比；浏览器不给总大小时，进度环一直转，右边显示已下载的大小。展开面板时，左上角也有一个进度小胶囊。下载完成后刘海提示「已下载 · 文件名」4 秒，点它就把文件放进托盘并打开托盘页。同时下载完的几个文件合成一条「已下载 · N 个文件」，每多一个文件多停 1 秒（最多 8 秒），点一下全部放进托盘；完成提示排队再久也不会被丢掉。暂时读不到「下载」文件夹时，进度先收起，2 分钟内恢复的话，期间下载完的文件照样提示。需要「完整磁盘访问」；没开时不工作，也不会弹系统询问。设置… →「实时活动」→「下载进度」可以关 |
| 正在播放与提示的先后 | 一次只显示一个：插电、耳机、下载完成这类一下就结束的提示，会暂时盖住正在播放的两翼，结束后回到音乐；下载进行中时两翼先给下载用。面板打开时不弹这类提示 |
| 灵动岛样式 | 没有刘海的屏幕（外接显示器等）上，ShelfU 总是一颗悬浮的灵动岛：默认在屏幕顶部正中，一颗 120 × 30 的小黑胶囊，四个角都是圆的，悬停、点开、拖文件进来、各种提示都和刘海一样。有刘海的 MacBook 可以在 设置… → 通用 →「刘海样式」里选「灵动岛」，胶囊在刘海下面 6pt；默认仍是刘海样式 |
| 拖动灵动岛 | 灵动岛样式下，按住小岛拖动，它跟着指针走，松手就留在那里；按下不动（移动不超过 4pt）就松开，仍然是点开面板。位置按屏幕分别记住，重启后还在。小岛不会高过默认位置，也会自动停在屏幕内，保证面板向下展开时完整可见。面板、提示、拖文件进来和拖窗口分屏都跟着小岛走；刘海拖放保护只在小岛贴着屏幕顶部时起作用。设置… → 通用 →「灵动岛位置」→「恢复默认位置」回到屏幕顶部。刘海样式不能拖 |
| 拖窗口到刘海分屏 | 拖着任意应用窗口的标题栏往刘海走，刘海长出「排列窗口」面板：左半、全屏、右半、左 1/3、中 1/3、右 1/3。指针停在哪一格，屏幕上就用蓝色框预览窗口会落在哪儿；松手窗口就排好（大小按窗口所在屏幕去掉菜单栏和 Dock 的区域算）。拖离刘海就收回，什么都不改。拖文件时照旧出现投放区。应用不允许改大小时只移动窗口，并提示「这个窗口不能调整大小」。需要「辅助功能」权限，没开时格子变灰并给出「开启」按钮。设置… → 通用 →「拖窗口到刘海分屏」可以关 |
| 检查与安装更新 | 右键点菜单栏图标 → 「检查更新…」手动查询；有新版本时页面底部出现提示、菜单多出「安装更新（vX）…」，选择后才开始下载；装好后菜单项变成「重新启动 ShelfU 完成更新」。后台检查每天一次，在 设置… → 通用 → 「自动检查更新」关闭（详见「自动更新」） |
| 查看 AI 用量 | 先在 设置… → AI 用量 打开「在刘海里显示 AI 用量」（默认关闭）：小岛上会多出一个页面图标。页面一屏看全、不用滚动：左栏是 Codex 与 Claude Code 的套餐额度卡（每张卡内外双圈：外圈每周、内圈 5 小时；悬停看重置时间，套餐有按模型的每周额度时也在悬停里列出），右栏是本机 token 用量（今天 / 7 天 / 30 天 / 全部，Token / 请求 / 费用 / 缓存命中四个数字，按来源叠加的柱图与图例，悬停 Token 或费用看它的组成部分），右上角的刷新按钮更新数据。额度默认显示「已用」，在 设置… → AI 用量 →「额度显示」可以改成「剩余」；已用到 90% 及以上显示红色。各额度卡和本机来源都能在同组设置里单独关掉 |
| Claude Code 额度从哪来 | ShelfU 运行本机装好的 Claude Code 的 `/usage` 命令读取额度，数字和重置时间与 Claude Code 自己显示的一致。没装 Claude Code 时卡片显示「未找到 Claude Code」，ShelfU 不会替你下载。登录过期、额度用完会直接显示，不会用上次的数字盖住 |
| 刷新 AI 用量 | 打开这一页或点刷新都会查询；点击后提示「正在刷新…」，刚查过时提示还能等多久再查。Claude Code 最多 30 秒查一次；页面一直开着时，只有你用过 Claude Code 才会每 5–15 分钟再查一次。上次查到的结果会保存，重启后打开先显示它。收起或切页不会再让已返回的额度结果丢失 |
| 退出 ShelfU | 右键点菜单栏图标，选择“退出 ShelfU” |

面板与刘海融为一体：有刘海的 Mac 上纯黑的小岛和面板从刘海里长出来、分不出边界；没有刘海的显示器上同样从顶部中央展开成一块黑色圆角面板。空闲时窗口贴在顶边且完全透明；只有画出来的黑色块接收鼠标，旁边的菜单栏照常可点，面板下面和两侧的应用也照常可点。

文字历史默认最多保留 **30 条文字**（设置… → 剪贴板 → 「保留条数」可改为 100 或 300 条，右键菜单栏图标 → 「剪贴板记录」同款选项），单条文字不限制长度。列表只显示简短摘要，单击复制或拖出时仍是完整正文。重复文字移到顶部，不新增重复项；文件和图片不占文字限额，也没有数量上限，不需要时手动移除即可。置顶的文字不占限额（不会被淘汰），两个标签页都把置顶项排在最前。

每条剪贴板记录会记住复制它的应用；右键剪贴板条目可以选择「不再记录来自该应用的内容」，该应用的标识符会写入 `settings.json` 的 `excludedApps`（不区分大小写）。想恢复记录，在 **设置… → 剪贴板 → 排除的应用** 里点该行的「移除」，或退出 ShelfU 后从 `settings.json` 里删掉它。

小岛分两行：上面那一行在刘海两侧，右边是设置和收起（左边空着）；下面一行左边是迷你播放器，没有在播放时显示「托盘 N 项 · 剪贴板 N 条」，右边每个页面一个图标——主页、托盘、剪贴板、工具，开了 AI 用量时再加一个。鼠标停在图标上会显示名字，点一下就从岛上展开那一页。

展开的页面都是 420 × 250：上面还是菜单栏那一行（左边多出正在进行的事的小胶囊），下面是返回行：最左是页面名（主页、托盘、剪贴板、工具、AI 用量），只是一行普通标题（不是按钮，点不了），不显示数量；后面是页面图标（最多 5 个）和这一页自己的按钮。这些图标顺序固定，当前页也在里面，它下面有一个底色胶囊；页面名占的位置一样宽，所以切页时图标不会移动，只有胶囊滑到新图标上，标题在同一位置交叉换成新页的名字。AI 用量页的数据时间（如「5 分钟前的数据」「正在更新…」）显示在右边的刷新按钮旁。内容区固定 396 × 174，内容多时在页内滚动：哪一侧还有内容，那一侧靠近边缘的几行就逐行虚化（剪贴板约 15pt、托盘和工具约 24pt），滚到头的那一侧不再虚化，完全不在边带里的行也不处理；切页的那 240 毫秒里暂停虚化。托盘页显示全部内容，剪贴板页只显示剪贴板收录的文字和图片。按 `⌃⌥V` 会直接打开剪贴板页并把焦点放进搜索框，全程不需要鼠标（这时整块面板会下移到菜单栏之下）；复制选中项后收起，并把焦点交还给你之前所在的应用。这个快捷键按下时 ShelfU 才会短暂获得键盘，其余打开方式（悬停、拖入、单击图标）一如既往不抢焦点。

当前页有未置顶的内容时，返回行右边会显示“清空”按钮：点击一次移除这一页里置顶以外的项目并立即生效，误清空不会弹确认框，请留意。剪贴板截图和复制的图片同时出现在托盘页和剪贴板页，清空（或右键「移除」）只把它移出当前这一页，另一页照常保留：在托盘页清空，剪贴板记录还在；在剪贴板页清空，托盘里的截图还在。已经从另一页移出的截图，再从这一页移除时才真正删除。剪贴板文字只在剪贴板页，在那里清空就是删除。再次复制同一内容，它会回到两页。置顶的项目连同 ShelfU 替它们保存的图片会保留下来；真正删除的项目会删除 ShelfU 自己保存在 `images/` 里的剪贴板图片与截图，但文件引用指向的原文件始终不会被删除；只想移除个别项目时，右键该项目 → 「移除」。

自动清理每小时检查一次，选择后立即执行一次。“超过 N 天”从项目最近一次放入托盘算起：同一内容再次复制或拖入会重新计时。清理与“清空”一样，只删除 ShelfU 自己保存的图片，绝不删除文件引用指向的原文件。

面板展开且你正在使用时，ShelfU 会临时占用空格键和 Esc（焦点在剪贴板搜索框时不占用，按键留给输入）；点一下其他应用就会归还。

文件拖入只记录路径，不复制原文件。原文件被移动或删除后，再打开托盘会标灰并显示“文件已移动”；可以手动移除该项。重启时会清理真正不存在的引用。

图片较多时会分批生成缩略图，相机照片会按照片记录的方向显示。再次复制同一张图片时，ShelfU 会检查已保存的内容；如果文件被改写或损坏，会用本次复制的原图恢复。

拖拽进入顶部接收区后如果没有放入内容，离开接收区或面板后会自动缩回刘海。悬停只显示探头胶囊，不会自行展开；单击胶囊或快捷键唤出的面板会保持展开，直到你明确收起。个别应用的拖拽不经过系统拖拽剪贴板，刘海可能不会探头；这时按快捷键打开托盘再拖进去。

## 设置窗口

右键点菜单栏图标 → **设置…** 会打开一个普通窗口，把所有偏好集中在一处。窗口居中出现在光标所在显示器上，已经开着时再次打开只会把它调到最前，不会开出第二个。

| 分组 | 内容 |
| --- | --- |
| 系统权限 | 放在最上面，只有一行、一个开关：全部开好时开关打开、写「已全部开启（3/3）」；没开全时开关关着、写「还差 N 项：……」。打开开关就按顺序带你在系统设置里开；进行中写「第 i 项，共 3 项：……」，可以「停止」；最后显示「重新打开 ShelfU」。全部开好后再点开关不会关掉权限（只能在系统设置里关），会打开「隐私与安全性」。设置文件损坏时这一组照常可用 |
| 通用 | 「开机时自动启动」开关（macOS 13+，通过 SMAppService 注册为登录项）；「自动检查更新」开关（默认开启，见「自动更新」一节）；「刘海样式」刘海 / 灵动岛（默认刘海；没有刘海的屏幕总是灵动岛）；「语言」跟随系统 / 简体中文 / English（默认跟随系统：Mac 的首选语言是中文就显示中文，简体、繁体都显示简体中文，其他语言显示英文；切换立即生效，不用重新打开）；显示灵动岛时多一行「灵动岛位置」和「恢复默认位置」按钮；「拖窗口到刘海分屏」开关（默认开） |
| 实时活动 | 「充电提示」「耳机连接提示」「下载进度」三个开关，默认都开 |
| AI 用量 | 「在刘海里显示 AI 用量」总开关（默认关）；下面一张表格按工具 × 来源勾选：「套餐额度」列管 Codex、Claude Code 的额度查询（omp 那格是「—」，没有额度可查），「本机用量」列管 omp、Claude Code、Codex 的本地记录统计；「额度显示」已用 / 剩余（默认已用）；关掉总开关后表格整体变灰不可点、勾选状态保留 |
| 剪贴板 | 「保留条数」30 / 100 / 300 三档；「排除的应用」列表（图标 + 应用名 + bundle id），每行右侧「移除」按钮。加入列表仍用条目右键菜单里的「不再记录来自…」。剪贴板记录始终开启，没有总开关 |
| 托盘 | 「自动清理旧内容」从不 / 1 天 / 7 天 / 30 天；「拖出后从托盘移除」开关（默认关，置顶的项目保留）；「刘海显示正在播放」开关 |
| 快捷键 | 只读展示 `⌃⌥Space` 显示/收起、`⌃⌥V` 剪贴板搜索、`⌃⌥O` 框选文字（快捷键是编译期常量，改它需要重新打包） |
| 底部 | 版本号，以及「打开数据文件夹」按钮（在 Finder 里打开 `~/Library/Application Support/ShelfU/`） |

每个控件改完**立即生效**，和菜单栏子菜单调用的是同一套设置逻辑，所以两边永远不会不一致：在窗口里改完，菜单栏再打开时显示的就是新状态（反过来也一样）。内容超出窗口高度时窗口内部滚动；按 `Esc` 或 `⌘W` 关闭窗口。

**开机时自动启动**需要 `ShelfU.app` 在“应用程序”文件夹里：注册失败时（例如从别处直接运行开发版）原因会直接显示在开关下方，不会静默失败。开关状态每次打开窗口时都从系统重新读取，所以你在系统设置里手动改过也会如实显示。

**settings.json 损坏时**，窗口顶部会显示红色提示条，说明设置已按默认值运行，并且「AI 用量 / 剪贴板 / 托盘」三组控件与「自动检查更新」开关全部锁定（置灰、点不动），避免把坏文件覆盖成一份看似正常的默认设置；系统权限、快捷键和开机启动不受影响。修好文件后重新打开 ShelfU 即可恢复。

## 开机自动运行

1. 打开 **设置…**（右键菜单栏图标 → 设置…）。
2. 在「通用」里打开 **开机时自动启动**。
3. 下次登录后 ShelfU 会自动常驻菜单栏。

如果注册失败（窗口里会显示原因），可以用系统自带的方式手动添加，效果相同：

1. 确认 `ShelfU.app` 已经放在“应用程序”文件夹。
2. 打开 **系统设置 → 通用 → 登录项**（部分系统叫“登录项与扩展”）。
3. 在“登录时打开”的列表点击 **+**，选择 `ShelfU.app`。

## 自动更新

正式版 ShelfU 会自己检查新版本：启动后不久查一次，之后每天一次，查询对象是本项目在 GitHub 的**最新 Release**（`henryyu333/shelfu`）。如果你另外开启了 AI 用量页，它还会向 Codex 与 Claude Code 各自的官方地址查询套餐额度（见「数据与隐私」）。除此之外没有其他网络请求——更新检查是标准的 HTTPS GET，User-Agent 只写明应用名与版本（如 `MyGo/0.5.5 ShelfU/1.10.0`），不发送任何个人信息、设备标识或使用数据；更新包附带数字签名，安装前会验证签名与完整哈希，只有用发布方私钥签名的版本才会被装上。

发现新版本时不会有弹窗打扰：页面底部出现一行提示，菜单栏图标的右键菜单里多出「安装更新（vX）…」。只有你选择它才会下载并替换应用；装好后菜单项变成「重新启动 ShelfU 完成更新」，重启后进入新版本（也可以直接退出再打开）。随时可以用右键菜单的「检查更新…」手动查询。

不想让它联网检查：设置… → 通用 → 关闭「自动检查更新」，立即生效；也可以先退出 ShelfU，把 `settings.json` 里的 `"autoCheckUpdates"` 改成 `false` 再打开。关闭后手动检查仍然可用。开发构建（`go build`/`mygo dev` 的产物）不做检查，菜单里的检查会说明该构建未启用自动更新。

提醒：从 Shelf 换到 ShelfU 时，macOS 会要求把系统权限再开一次（设置… → 系统权限 的开关）。ShelfU 的正式发布版用固定签名，之后更新会保留授权；自己编译的构建每次签名都会变，可能要重新开启。

从 Shelf 升级：ShelfU 是 Shelf 的新名字。ShelfU 第一次打开时，会把 `~/Library/Application Support/Shelf/` 里保存的内容复制到 `~/Library/Application Support/ShelfU/`；旧文件夹保持原样，确认内容都在以后可以删掉。macOS 会把 ShelfU 当成一个新应用，所以系统权限和「开机时自动启动」要重新打开一次。

- 在 Shelf 里应用内更新：更新装好后，在“应用程序”里打开 Shelf。它会自己改名为 `ShelfU.app` 并以 ShelfU 打开。
- 用 ShelfU.dmg 安装：先退出 Shelf，把 `Shelf.app` 移到废纸篓，只让 ShelfU 使用你的内容。

## 数据与隐私

数据保存在：

```text
~/Library/Application Support/ShelfU/
  state.json        托盘内容（含图片清单）
  settings.json     设置
  layout.json       主页的小组件、工具页的卡片排列和桌面固定项的位置（旧版本的文件打开时自动迁移；文件损坏时按默认布局显示，不会被覆盖）
  images/           剪贴板图片与截图
  .lock             防止同时运行两个 ShelfU 的锁文件，运行时不要删除
  usage-cache/      AI 用量页的本地用量统计缓存（开启过才有，删掉只是下次统计变慢）
```

在 Finder 按 `⌘⇧G`，粘贴 `~/Library/Application Support/ShelfU/`，即可找到它。备份时先退出 ShelfU，再复制整个文件夹；恢复时同样先退出。

剪贴板记录始终开启：复制的文字和截图都会自动收进 ShelfU。不想让某个应用里复制的内容被记录，右键它的剪贴板条目 →「不再记录来自『应用名』的内容」；临时不想记录某段内容，先退出 ShelfU 再复制。各种偏好都可以在设置窗口里改；它们存在 `settings.json` 里：`"clipboardLimit"`、`"retentionDays"`、`"excludedApps"`、`"autoCheckUpdates"`，正在播放开关对应 `"islandNowPlaying"`，拖出后从托盘移除对应 `"removeAfterDrag"`，AI 用量页的开关都在 `"aiUsage"` 里（默认 `enabled` 为 `false`，各来源开关默认 `true`）；除 `"retentionDays"`（默认 0，不清理）、`"clipboardLimit"`（默认 30）、`"removeAfterDrag"`（默认 `false`）与 `"aiUsage.enabled"` 外默认都是 `true`。旧版本留下的 `"clipboardHistory"` 不再起作用，下次保存设置时会自动去掉。文件写错时，ShelfU 会提示并按默认设置运行，不会改动你的文件；此时设置窗口会锁定这几组控件，等你修好文件再改。

同一时间只能运行一个 ShelfU：再打开第二个时，它会提示“已在运行”并立即退出，不会影响已有内容。

**文字历史以明文保存，不提供加密。** 密码管理器标记为隐私的密码不会被记录，但其他复制的内容（验证码、客户资料等）都可能被收进历史。不希望某段内容被记录时，先退出 ShelfU 再复制。删除文件引用不会删除你的原文件；在剪贴板页移除剪贴板图片会清理 ShelfU 自己保存的图片（托盘页的移除只让它不再显示在托盘）。

ShelfU 不上传任何内容：没有云同步、遥测或统计。联网请求只有两类：向 GitHub Releases 的自动更新检查（见「自动更新」一节：默认开启，可在设置里关闭；请求不含个人信息），以及可选的 AI 用量页的额度查询。日常使用不需要任何授权。三项系统权限都可选，用设置… → 系统权限 的一个开关一起开：「完整磁盘访问」让从下载、桌面、文稿等文件夹拖入时不再弹窗；「辅助功能」用于刘海拖放保护，拖着内容靠近刘海时，指针会停在托盘接收区里，不会顶到屏幕最上沿；「屏幕录制」只给「框选文字」用（见下）。设置窗口里这一行写「已全部开启（3/3）」就说明都已生效。

**框选文字**需要「屏幕录制」授权，只在你使用它时才会提示。它只截取你框选的那一块区域，文字在本机识别后放进剪贴板，截图不保存、不上传。授权后要退出并重新打开 ShelfU 才生效。

**AI 用量页**默认关闭。打开后，Codex 的额度用本机保存的登录信息（`~/.codex/auth.json`）向 chatgpt.com 查询；Claude Code 的额度通过运行你装好的 Claude Code 的 `/usage` 命令读取，由 Claude Code 自己照常联系 Anthropic，ShelfU 只读钥匙串里的 Claude Code 凭据来判断账号和套餐。登录信息不会发给任何其他地方，ShelfU 也不会替你登录。最近一次查到的额度保存在数据文件夹的 `quotas.json`。「本机用量」只在这台电脑上读取 omp、Claude Code、Codex 的会话记录文件做汇总，统计结果不上传；每个来源都可以在设置里单独关掉。关掉总开关后页面消失，不会再有任何读取和查询。

如果保存的数据无法读取，ShelfU 会提示原因；确认后本次启动退出，不创建菜单栏托盘或占用快捷键，也不会用空内容覆盖原文件。请先备份数据文件夹再处理，然后重新打开 ShelfU。

## 卸载

1. 右键菜单栏图标 → 退出 ShelfU。
2. 把“应用程序”里的 ShelfU 移到废纸篓。
3. 如果连保存的内容也要删除，删掉 `~/Library/Application Support/ShelfU/` 文件夹。

## 修改快捷键与灵敏度

设置窗口里的「快捷键」一栏只是只读展示：快捷键和灵敏度都是编译期常量，要改需要改源码后自己重新打包（需要 Go 1.27 或以上以及 Xcode Command Line Tools）。

1. 下载本项目源码，用代码编辑器打开 `config.go`。
2. 找到 `trayShortcut = "Ctrl+Alt+Space"`，改成你想要的组合，例如 `"Ctrl+Alt+S"`。只改引号里的内容。
3. 同一个文件里还可以调整：`dropBandPadX`（投放带相对刘海的水平外扩，默认 24pt：触发带就是刘海宽度左右各加这么宽，刘海宽度至少按 180pt 计）、`guardDropPad`（投放带比菜单栏向下多出的高度，默认 16pt）、`notchHoverPadX` / `notchHoverPadY`（空手悬停刘海的感应余量，8×4 pt）、`edgeLeaveDelay`（离开后多久收起，350 毫秒）。
4. 在终端进入项目目录，运行：

```sh
go run github.com/egoist/mygo/cmd/mygo build
```

5. 打包好的 `ShelfU.app` 和 `.dmg` 在 `dist.noindex/darwin-arm64/` 里。先退出正在运行的 ShelfU，再用新的替换。

设置窗口「快捷键」一栏会自动跟着变，不需要另外修改。
